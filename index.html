Advanced AI Model

Get Started in Minutes

1

Clone Repository

Get the latest version from GitHub

git clone https://github.com/U-justine/VideoActionRecognition-AI-VIDEO-RECOGNITIONS.git cd VideoActionRecognition-AI-VIDEO-RECOGNITIONS
2

Setup Environment

Create virtual environment and install dependencies

python3 -m venv .venv source .venv/bin/activate pip install -r requirements.txt
3

Run Application

Launch the Streamlit web interface

streamlit run app.py
4

Upload & Analyze

Upload your video and get instant AI-powered action recognition results!
